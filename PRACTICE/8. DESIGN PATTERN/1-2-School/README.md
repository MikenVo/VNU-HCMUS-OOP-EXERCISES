# OOP Exercise - Build Pattern
- The exercise contains:
1. Exercise 1: Rebuild the school based on the Prototype Build Pattern.
2. Exercise 2: Rebuild the school administration based on the Singleton Build Pattern.

- The files:
1. `school.h` - contains the class definition for the classes (Personnel, Administration).
2. `NhanVien.cpp` - contains the implementation of the NhanVien class and its inheritances.
3. `PhongQuanLy.cpp` - contains the implementation of the PhongQuanLy class.
4. `main.cpp` - contains the main function to run the program.
5. `Personnel.png` - contains the UML diagram.

- Run the program:
1. Open the terminal and navigate to the project directory.
2. g++ main.cpp NhanVien.cpp PhongQuanLy.cpp -o output.exe
3. Run the output.exe file to see the result.
